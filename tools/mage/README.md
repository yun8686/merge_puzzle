# 魔導士の姿

![10人](sheet.png)

`lib/ui/mage_art.dart` の座標はここから生成している。**Dart を手で直さないこと。**

敵（`tools/foe/`）と同じ仕組み。ラスター画像ではなく `CustomPainter` で描く。
姿が出るのは編成の枠（38px）・名簿の札（38px）・一党の帯（21px）で、実機では
20〜40px しかない。画像を置いても潰れて読めず、ベクターなら解像度に追従し、
色を `Palette.mageColor` から取れるので盤面に敷かれるマナの色と必ず揃う。

## 人を描かない

**姿は人ではなく、その魔導士の力そのもの**を描いている。20px の丸の中に人の
形を入れても、誰だか分からない点の集まりにしかならない。炎・滴・稲妻のように
輪郭だけで意味が分かる形に寄せてある。

相ごとに形の系統を揃えてあるので、姿だけで相が読める。

| 相 | 形 |
|---|---|
| 熱 | 炎（焔・烈火）と渦（風） |
| 冷 | 滴（冷の従者・氷雨）と六花（霜） |
| 雷 | 稲妻（雷の従者・電）と盾（盾） |

## 格の梯子

**従者は輪郭だけ、招ける魔導士は塗り潰し。** 同じ相でも格の差が形で出る。
敵が「守りが厚いほど枠を使い切る」のと同じ考え方。

## 直し方

リポジトリのルートから。Pillow だけあれば動く。

```bash
pip install pillow
cd tools/mage
python3 preview.py 160 sheet.png   # 上の並びを描き直す
python3 emit_dart.py               # lib/ui/mage_art.dart を書き換える
```

`shapes.py` を直す → `preview.py` で見る → 納得したら `emit_dart.py`。
書き出し先は `lib/ui/mage_art.dart` に固定してある。

小さいところに出るので、形を直したら `python3 preview.py 22` のように小さい値
でも描いて、潰れていないか見ること。

## 形の決まり

`tools/foe/README.md` と同じ。座標は 0〜1 の正方形で、使える描画は3つだけ。

| | |
|---|---|
| `('poly', 層, [(x,y), ...])` | 閉じた多角形を塗る |
| `('circle', 層, (cx, cy, r))` | 円を塗る |
| `('line', 層, [(x,y), ...], w)` | 折れ線を太さ w・丸端で引く |

層は `fill`（本体）→ `hole`（くり抜き）→ `glow`（光る芯）の順。くり抜きは
背景色で塗るのではなく `BlendMode.clear` で抜くので、どの色のパネルの上に
置いても穴が背景とずれない。

炎・滴・稲妻・六花・渦・雲は `shapes.py` の先頭に部品として置いてある。同じ
形を何度も書かないこと。

## 魔導士を足したとき

`MAGES` と `ORDER` と `PHASE` の3つに足して `emit_dart.py` を走らせる。
忘れると実機で落ちるので、`test/mage_art_test.dart` が名簿の全員ぶん描いて
確かめている。
