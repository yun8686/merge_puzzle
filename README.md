# 奇偶チェイン (Parity Chain)

奇数と偶数を交互になぞって、まとめて消すパズル。Flutter 製。

```
指でなぞる:  3 → 4 → 7 → 2 → 5 → 6 → 1
            奇   偶   奇   偶   奇   偶   奇
離すと全部まとめて消える。長いほど点が跳ねる。
```

## ルール

- 盤面は 6 × 8。タイルは **奇数=暖色 / 偶数=寒色** で塗り分けられている。
- 上下左右に隣接するタイルを指でなぞって繋ぐ。**連続する 2 枚は必ず偶奇が交互**であること。
- 3 枚以上繋がった状態で指を離すとチェイン成立。なぞったタイルが全部消え、**終端に合計値の新しいタイル**が残る。
- 消えた跡は重力で詰まり、上から新しいタイルが降ってくる。
- 補充されるタイルは **65% が奇数**。奇数同士は繋げないので、**偶数は枯れていく希少資源**になる。
- 繋げる手が 1 つも無くなったらゲームオーバー。

### 戦略になっているところ

長く繋ぐほど気持ちよく、点も伸びる。しかし長いチェインは偶数を大量に食い潰すので、盤面の寿命を縮める。
一方で終端に残るタイルの値は合計値なので、**パスの組み方で合計を偶数にすれば偶数を補充できる**。
「今欲張るか、盤面を延命するか」がプレイヤーの判断になる。

画面上部の「偶数」ゲージが、そのまま盤面の寿命を表している。

## なぜこのルールになったか

当初は 2048 の変種（奇数と偶数がマージできる）として設計していたが、成立性をシミュレーションで検証した結果、
方向を変えた。記録として残しておく。

| 検証した案 | 結果 |
|---|---|
| 奇数と偶数なら何でも合体（素直な解釈） | **破綻**。奇数+偶数の和は必ず奇数なので偶数が供給されず、平均30手で盤面が奇数だらけになって詰む |
| 上記＋同じ数同士も合体 | **緩すぎ**。AI が一度も負けず、緊張感が消える |
| 偶奇ラダー（1,2,3,4,7,8,15,16,…） | **実質 2048**。目玉の「奇数+偶数」マージは全体の 15.8% に留まり、28% は 2048 と同一の倍加、残りは 1 の端数処理だった。奇数を作る動機が無く、色分けが装飾に落ちる |
| 奇数を不安定化して連鎖させる | **爽快感が出ない**。平均 1.18 連、3連以上は 2.0% 止まり |

根本的な原因は、2048 系が「完全一致した 2 枚だけが合体する」ため **1 手あたりの消滅数が構造的に 1 前後に固定される**こと。
締めれば連鎖せず、緩めれば緊張感が死ぬ。数字のルールをいじる方向では抜けられなかった。

そこで消滅条件そのものを変え、**1 回の入力で 7〜12 枚が同時に消える**現在の形にした。

シミュレーション上の挙動（6×8 / 4方向 / 奇数率 65%）:

- 上級者相当（常に最長経路を取る AI）: 中央値 220 手で決着、パス長 平均 4.9 枚・最大 14 枚、6 枚以上の大消しが 23.8%
- 初心者相当（適当に短く取る AI）: パス長 平均 3.8 枚

腕の差がパス長にそのまま出て、かつ有限手で決着する。

## 開発

```bash
flutter pub get
flutter test          # ロジック + ドラッグ操作のウィジェットテスト
flutter analyze
flutter run
```

### 構成

| ファイル | 役割 |
|---|---|
| `lib/game/board.dart` | 盤面ロジック。パス判定・消去・重力・補充・詰み判定。UI 非依存で単体テスト可能 |
| `lib/game/game_controller.dart` | なぞり中の状態、スコア、ゲームオーバー遷移 |
| `lib/ui/board_view.dart` | なぞり入力と演出（経路の線、弾ける消滅、パーティクル、画面シェイク、触覚フィードバック） |
| `lib/ui/game_screen.dart` | スコア表示、偶数ゲージ、ヒント、リスタート |
| `lib/ui/particles.dart` | パーティクル |
| `lib/ui/theme.dart` | 配色とチェイン称号 |

### 調整できるパラメータ

| 場所 | 意味 |
|---|---|
| `Board.oddChance` (既定 0.65) | 補充時の奇数率。上げるほど偶数が枯れやすく難しくなる |
| `Board.rows` / `cols` (既定 8 × 6) | 盤面サイズ |
| `Board.minPathLength` (既定 3) | チェイン成立に必要な枚数 |
| `Board.scoreFor` | 得点式。倍率は線形（3枚=等倍、12枚=10倍）。指数にすると数手で桁が壊れる |
